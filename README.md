# 랜덤 디펜스 — 학습용 프로토타입

영웅을 소환하고 같은 영웅 셋을 합성해 20웨이브를 버티는 세로형 랜덤 디펜스 웹 게임입니다.
게임 구조를 공부하려고 직접 만든 프로토타입입니다. 그림은 이 게임을 위해 AI 로 생성했고(다른 게임의 그림을 참고 자료로 쓰지 않음), 소리는 아래 출처의 것을 잘라 썼습니다.

- 플레이: 이 저장소의 GitHub Pages 주소를 폰 브라우저로 엽니다.
- 앱처럼 쓰기: 브라우저 메뉴 → **홈 화면에 추가**. 주소창 없이 전체 화면으로 열리고, 한 번 연 뒤에는 인터넷 없이도 열립니다.
- 진행(열쇠·보석·유물·기록)은 그 브라우저에만 저장됩니다.

이 저장소에는 빌드 결과(`index.html` 한 파일)만 있습니다. Phaser 4 · TypeScript · Vite.
